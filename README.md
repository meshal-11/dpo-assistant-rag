## 📌 المشكلة والنطاق (Problem & Scope)

### المشكلة:
تتضمن القواعد التنظيمية لحماية البيانات تفاصيل قانونية وإجرائية دقيقة قد يصعب على المختصين والمؤسسات استخلاصها بسرعة، كما أن نماذج اللغة الكبيرة العامة (LLMs) قد تعاني من الهلوسة أو اختلاق أرقام مواد ومراسيم وصفحات غير دقيقة عند سؤالها عن تنظيمات محلية محددة.

### النطاق:
- **مصدر معرفة وحيد ومغلق**: وثيقة PDF محددة بعنوان "مشروع قواعد تعيين مسؤول حماية البيانات الشخصية" (11 صفحة).
- **إجابات موثقة بأرقام الصفحات**: كل إجابة يقدمها النظام تكون مدعومة بأرقام الصفحات الحقيقية في المستند (1-based page numbers) والاقتباسات النصية الصريحة.
- **قاعدة الامتناع الصارم (Abstention)**: يصرّح النظام بوضوح واعتذار عندما لا تتضمن الوثيقة إجابة عن السؤال المطروح.
- **حماية من الحقن (Injection Defense)**: التعامل مع نصوص المستند كبيانات استرشادية سلبية، وليس كتعليمات قابلة للتنفيذ.
- **بنية محلية خفيفة**: لا يتطلب المشروع قواعد بيانات متجهات خارجية (Vector Databases)، بل يعتمد على حساب تشابه جيب التمام المباشر باستخدام `NumPy`.

## 🚀 المميزات الرئيسية (Key Features)

1. **واجهة دردشة عربية عصرية (RTL)**:
   - تصميم متجاوب وأنيق ومريح للعين مع هوية بصرية متميزة.
   - أسئلة مقترحة سريعة لاختبار أحوال ومتطلبات التعيين والمهام.
   - عرض المصادر الداعمة والاقتباسات النصية أسفل كل إجابة بأمان تام ضد ثغرات XSS.
2. **استخراج متقدم للنصوص العربية**:
   - استخدام `PyMuPDF` لمعالجة اتجاه الكلمات العربية بدقة.
   - تطبيع اليونيكود (Unicode Normalization - NFKC) وإزالة التطويل الزخرفي (Tatweel).
   - تصحيح العكس البصري في نصوص المراسيم الملكية في الصفحة 4 دون الإضرار ببقية الصفحات.
   - استبعاد أغلفة الوثيقة وفهرس المحتويات والترويسات المتكررة.
3. **تخزين مؤقت ذكي للمتجهات (Embeddings Cache)**:
   - حفظ المتجهات محلياً في `data/embeddings_cache.json` استناداً إلى بصمة رقمية SHA-256 للمستند والنموذج وإعدادات التقطيع.
   - تحميل فوري في أقل من 50 مللي ثانية دون إعادة طلب API.
4. **نماذج اقتصادية عالية الكفاءة**:
   - نموذج التوليد: `gpt-4o-mini` (فائق السرعة واقتصادي جداً مع دعم ممتاز للعربية).
   - نموذج التضمين: `text-embedding-3-small` (أبعاد 1536، منخفض التكلفة).
5. **معالجة متقدمة للأخطاء**:
   - تنبيهات واضحة عند غياب مفتاح API أو عند إدخال أسئلة فارغة أو تتجاوز الحد المسموح.
   - توثيق تفاعلي كامل عبر FastAPI Swagger على `/docs`.

```

│   ├── __init__.py

│   ├── style.css          # الأنماط والتنسيقات البصرية
│   └── app.js             # منطق التفاعل، واستدعاء API، وتصيير المصادر بأمان
├── docs/
│   ├── TECHNICAL.md       # التوثيق المعماري والتقني المفصل
│   └── EVALUATION.md      # تقرير التقييم واختبارات الصفحات وحالات الحافة
├── data/
│   └── مشروع+قواعد+تعيين+مسؤول+حماية+البيانات+الشخصية+2.pdf
├── requirements.txt       # حزم بايثون المطلوبة
├── .env.example           # قالب متغيرات البيئة
└── .gitignore             # استثناء المفاتيح والكاش والبيئة الافتراضية
```

## 🛠 المتطلبات الأساسية والتثبيت المحلي (Local Setup)

### 1. المتطلبات:
- نظام تشغيل: Windows أو macOS أو Linux.
- بايثون: الإصدار `3.10` أو أحدث.
- مفتاح صالح لخدمة [OpenAI API](https://platform.openai.com/api-keys).

### 2. خطوات التثبيت:

افتح موجه الأوامر (PowerShell أو Terminal) داخل مجلد المشروع:

```powershell
# 1. إنشاء البيئة الافتراضية وتفعيلها
python -m venv .venv
.\.venv\Scripts\Activate.ps1   # على ويندوز (أو: source .venv/bin/activate على لينكس/ماك)

# 2. ترقية مدير الحزم وتثبيت المتطلبات
pip install -r requirements.txt
```

### 3. إعداد متغيرات البيئة (`.env`):

انسخ ملف `.env.example` إلى `.env`:
```powershell
Copy-Item .env.example .env
```

افتح ملف `.env` وضع مفتاح OpenAI API الخاص بك:
```env
OPENAI_API_KEY=sk-proj-yourActualOpenAiKeyHere
OPENAI_CHAT_MODEL=gpt-4o-mini
OPENAI_EMBEDDING_MODEL=text-embedding-3-small
HOST=127.0.0.1
PORT=8000
API_TIMEOUT_SECONDS=30
MAX_QUESTION_LENGTH=500
```

> 🔒 **تنبيه أمني هام:**
> لا تقم مطلقاً برفع ملف `.env` أو مفتاحك إلى Git أو مشاركته مع أي شخص. تم تضمين `.env` تلقائياً في `.gitignore`.

## ▶️ تشغيل النظام (Running the Application)

شغّل الخادم المحلي باستخدام الأمر التالي:

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```

بعد بدء الخادم، افتح المتصفح على:
- 🌐 **واجهة الدردشة**: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
- 📖 **توثيق واجهة البرمجة (Swagger)**: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- 🩺 **فحص الحالة (Health)**: [http://127.0.0.1:8000/api/health](http://127.0.0.1:8000/api/health)
